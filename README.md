# MLP-Parabolic-Interpolation
Giải phẫu MLP trên PyTorch: Triển khai Backpropagation thủ công và tối ưu hóa bằng Nội suy Parabol (Brent's Method). Dự án tập trung mô phỏng toán học chuyên sâu sau quá trình huấn luyện mạng nơ-ron, thay thế optimizer truyền thống bằng logic nội suy để tìm cực tiểu hàm mất mát. Phù hợp cho học tập và nghiên cứu AI.
